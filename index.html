Search syntax

c:rg / color:rgCards with red and green in their colors
id:bant / identity:bantColor identity is within white/blue/green
t:creature / type:creatureType line contains "creature"
o:"draw a card" / oracle:...Oracle text contains the phrase
mv:3 / mv>=4Mana value comparisons (also cmc)
pow>=4 / tou<=2Power / toughness comparisons
loy>=5 / loyalty>=5Starting loyalty comparisons (planeswalkers)
r:mythic / rarity:mythicRarity
set:mh3 / s: / e: / edition:Set code
number:161 / cn:161Collector number
year:1993 / year<=2000Release year comparisons
date>=2020-01-01Release date comparisons
a:"jason chan" / artist:Illustrator name
ft:"draw a card" / flavor:Flavor text contains the phrase
wm:orzhov / watermark:Watermark
border:blackBorder color
frame:2015Card frame style/year
lang:ja / l:jaPrinted language
m:{2}{r} / mana:Exact mana cost string
produces:wgCan produce white and green mana
f:modern / format:modernLegal in a format
banned:standardCurrently banned in a format
restricted:vintageCurrently restricted in a format
usd>=50 / eur<=5Price comparisons
tag:removalFunctional tag: removal, boardwipe, cardadvantage, protection
kw:deathtouch / keyword:Has this exact keyword ability (Scryfall's keywords list)
is:foil / is:nonfoilOwnership condition
is:deckCurrently placed in a registered deck
is:commanderLegendary creature
is:split / flip / transform / meld / mdfc / dfcLayout checks
is:permanent / is:spellPermanent vs. instant/sorcery
is:promo / reprint / fullart / textless / reserved / digitalPrinting flags
is:hybrid / is:phyrexianMana cost symbol checks
is:vanillaCreature with no rules text or keywords
is:levelerHas "Level up"
-t:landExclude a term with a leading minus (works on any operator)
art:sword / atag: / arttag:Illustration tag — queries Scryfall live (needs internet)
otag:removal / function:removalScryfall's own oracle/functional tags — queries Scryfall live (needs internet)

Typed search terms and the filters on the left both apply at the same time — they're combined with AND.

art:, atag:, arttag:, otag:, and function: aren't stored locally, so using any of them sends your whole query to Scryfall's live search and intersects the results with your collection — this needs an internet connection and can take a moment for very broad tags.
